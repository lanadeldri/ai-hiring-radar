AI Hiring Radar

AI companies that are hiring right now, ranked by open engineering roles. Companies are found automatically from HN Who's Hiring, the YC directory and funding news; every number comes straight from each company's public job board. Filter by role to find, say, every Forward Deployed Engineer opening.

Role

Refresh the data

Run python fetch_jobs.py --detect. It writes data/companies.json and data/jobs.json, and this page picks them up automatically.

Add a company

Add a row to data/companies.csv with the name, website and job-board slug. Or let discover.py find them: it reads HN Who's Hiring, the YC directory and funding news.

Daily refresh

Push to GitHub and the included Action runs the script every day and commits fresh data. Turn on GitHub Pages for a free public site.
