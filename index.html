AI Hiring Radar

AI companies that are hiring right now, ranked by open engineering roles. Every number comes straight from each company's public job board on Ashby, Greenhouse or Lever.

Refresh the data

Run python fetch_jobs.py --detect. It writes data/companies.json, and this page picks it up automatically.

Add a company

Add a row to data/companies.csv with the name, website and job-board slug. Leave the ATS blank if unsure; --detect tries all three.

Daily refresh

Push to GitHub and the included Action runs the script every day and commits fresh data. Turn on GitHub Pages for a free public site.
